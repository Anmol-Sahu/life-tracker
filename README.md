# Life — Personal Life Tracker V1

Mobile-first PWA. Stores data locally in the browser using localStorage.

Features: Dashboard, Things, Recurring, Planned, Expenses, automatic recurring next-date calculation, installable PWA shell, basic offline caching.

Run locally: `python -m http.server 8000` then open `http://localhost:8000`.

For phone installation, deploy the folder to an HTTPS URL. Do not treat this V1 as production-ready for sensitive data until cloud sync, backup/export, authentication and stronger security are added.
